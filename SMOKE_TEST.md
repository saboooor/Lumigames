# Paper server acceptance checks

Use a disposable Paper 1.21.10+ server, compatible Java clients and two accounts before production deployment. Automated tests do not verify actual Minecraft client rendering, other plugins' event handlers, or chunk loading.

1. Start with the built JAR. Verify `/lg` and `/lg admin` render native dialogs, sprites and tooltips. Verify pagination after creating more than ten arenas. Escape from an input dialog must leave its old value unchanged.
2. Create and enable the documented solo course. Carry named/enchanted items, armor, offhand items, levels and potion effects. Join, visit each checkpoint, revert, leave and verify exact equipment, levels, effects, game mode and location restoration.
3. Rejoin and verify saved progress resumes. Disconnect during the course and verify you return outside the game on login; join again and resume. Finish and verify the saved checkpoint clears, one win is recorded and winner commands run once.
4. Stop the server while a player is in a game. Restart and verify their original state is recovered. Repeat with an unclean process stop on a disposable server. Do not remove the recovery files between runs.
5. Use a test teleport-cancelling plugin to block return teleports. Verify recovery stays pending, gear cannot be transferred, and unblocking teleports completes recovery. Repeat when leaving while dead. Test a return world that is temporarily unloaded.
6. Join a multiplayer lobby with two players. Leave during countdown and verify cancellation. Join an observer and verify the observer does not satisfy the player minimum. Start a match and verify balanced teams, friendly-fire protection, kit selection and spectator boundaries.
7. Test each objective: kills, limited lives, spleef falling below the arena, CTF stealing/capturing/death/quit, infection survivor timeout, Juggernaut role transfer, treasure hints and distinct treasure detection, CUSTOM scoring and score-sign replay protection.
8. Break spleef snow and place supported solid blocks in a construction-enabled arena. Stop the match and verify restoration. Restart after an unclean stop and verify rollback. Verify containers, pistons, fluids, explosions, fire and external projectiles cannot alter arenas or damage outsiders.
9. Verify `/spawn`, `/home`, portals and external teleports cannot bypass leave/recovery. Confirm drop, pickup, crafting, containers, buckets, vehicles and armor stands cannot transfer game gear. Verify allowlisted chat commands still work.
10. Revoke play/admin/spectate permissions while dialogs are open. Click the stale actions and verify server-side checks still reject unauthorized changes.
11. Check behavior with the server's actual inventory, teleport, protection and economy plugins installed. Console rewards need those plugins' own acceptance checks.

12. Copy a real old Minigames data folder to the disposable server. Run `/lg admin migrate preview` from both a player and console; verify no files change. Apply, inspect the report and exact pre-import backup, verify originals are unchanged and imported arenas are disabled. Review bounds, loadouts (including item metadata, potion effects, armor and offhand), team spawns and timer changes. Set missing objectives, enable and play an imported arena. Repeat the import and verify existing arenas are skipped.

13. Link two differently positioned plates to the same checkpoint. Reach the first, revert, then reach the second and revert; each must return to the corresponding plate without advancing the checkpoint ID. Leave/rejoin and restart the server to verify the last selected solo plate persists. Verify other players retain independent selections. Check that future checkpoints cannot be skipped and earlier stages cannot reset progress. Test all plate types, including a linked heavy plate beside a separate finish plate. Unlink a saved plate and confirm a safe fallback; unlink the last plate and verify it no longer triggers while the checkpoint sign still works.

14. Use `/lg admin set-checkpoint <arena> <player> <checkpoint>` from a player and console. Verify advancing and rewinding checkpoint order, preserving elapsed time, selecting linked plates, optional teleporting, and offline solo assignment by cached name or UUID. Verify spectators, inactive racers, invalid plates and non-admins are rejected. Block the optional teleport and verify progress is still saved and `/lg revert` can retry.
